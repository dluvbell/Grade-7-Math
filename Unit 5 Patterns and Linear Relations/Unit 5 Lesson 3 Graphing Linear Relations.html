Rules to remember
  • From here on we write rules as equations. x is the term number (or whatever is counted along the bottom) and y is the term value. "Multiply the term number by 3, then add 2" becomes y = 3x + 2.
  • In y = mx + b: m is the constant rate and b is the initial value — the same two numbers you have been finding since Lesson 1.
  • The initial value is where the line crosses the vertical axis, because that is where x = 0.
  • The rate is one step across. Move one square to the right and see how far the line goes up or down. Up is positive, down is negative.
  • When the value goes down, write the starting number first: y = 40 − 3x, not −3x + 40. Both mean the same thing, but this unit uses the first form.
  • The graph now uses all four quadrants. x and y can both be negative, so read the axis labels carefully — they are written every two squares.
  • Two points fix a line. The crossing point on the vertical axis plus one step across is enough to draw it or to recognise it.
  • The same relation can be written more than one way. y = x + 2 + x + 2 and y = 2x + 4 are the same relation — collect the like terms and see.
